🛰️ Bem-vindo(a) à Estação Cronos, jovem cronauta! Aqui os verbos são os motores que controlam o tempo. Neste kit você vai treinar tudo o que cai na prova: o que é verbo; tempo, número e pessoa; os modos indicativo, subjuntivo e imperativo; as formas nominais; e os tempos do indicativo e do subjuntivo. Siga a ordem das missões abaixo. 🚀

📌 Como usar este material

  1. Comece pela Leitura Guiada: leia e escreva as respostas de cada estação.
  2. Faça o Quiz logo depois, para testar o que ficou fresco na memória.
  3. Use o Resumo para fechar as lacunas que o Quiz mostrou.
  4. Por fim, encare o Simulado valendo, como se fosse a prova.
👩‍👦 Dica para a família: o Quiz e o Simulado só liberam o gabarito comentado com um código (MED-XX-YY e SIM-XX-YY) que aparece no fim. O jovem aprendiz mostra o código a um adulto, que autoriza a correção. Assim ele resolve tudo com atenção antes de ver as respostas. Todo o progresso é salvo sozinho no navegador.
